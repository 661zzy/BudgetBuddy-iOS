# BudgetBuddy iOS working notes

- When adding any new story to `Resources/stories.json`, also add matching pixel-art scene artwork. At minimum, create the story-card image asset named `scene_<story_id_with_underscores>_s1` in `Assets.xcassets`.
- Keep generated story art consistent with `SCENE-ART-PROMPTS.md`: warm 16:9 retro pixel-art, Chinese student daily-life setting, no readable text, no logos, no real brands, no copyrighted characters.
- Do not leave new stories with only the emoji fallback unless the user explicitly asks for a temporary placeholder.
